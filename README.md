# Agent PRD Skill

把一个 AI 助手的点子，整理成开发者和 AI 编程工具都能接手的两份文档：一份说明**产品要做什么、怎样算做成**，另一份说明 **Agent 需要哪些工具、什么时候能调用、出错时怎么处理**。

适合正在规划客服、个人助理、资料整理或审核类 Agent 的产品经理、开发者，以及第一次把想法交给 AI 开发的人。

## 从一个记账助手开始

在 Codex 里调用技能，试着这样说：

> $agent-prd 我想给妈妈做个记账助手。她说“买菜 35 元”，助手就记一笔，回复金额和类别。听不清金额时先问她，绝不替她付款。

这句话已经交代了使用者、目标、一次记账的流程和权限边界，技能可以直接起草两份文档。

| 交付物 | 记账助手示例 |
| --- | --- |
| `PRD.md` 产品需求文档 | 写清妈妈说完一句话后应收到什么回复，并把“金额听不清就追问”写成可以验证的行为。 |
| `方案.md` 技术方案 | 说明何时可以调用记账工具，把付款列为禁止操作，并设计记账工具失败时的处理方式。 |

如果你只说“想做个记账助手”，技能会一次问一个关键问题，最多追问六轮。你确认整理好的需求后，它再出稿。“账本存在哪里”这类尚未决定的事项会标为**待确认**，方便你先审阅已经想清楚的部分。

## 在 Codex 中使用

在 macOS 或 Linux 终端运行：

```sh
mkdir -p ~/.agents/skills
git clone https://github.com/hexing-ai/agent-prd.git ~/.agents/skills/agent-prd
```

也可以从 GitHub 的 **Code → Download ZIP** 下载并解压，把含有 `SKILL.md` 的文件夹命名为 `agent-prd`，放进 `~/.agents/skills/`。

在准备保存文档的项目里新开 Codex 对话，输入 `$agent-prd` 和你的想法。默认交付位置为 `docs/产品名/PRD.md` 和 `docs/产品名/方案.md`。

## 在其他 AI 工具中使用

- **能读取项目文件的编程助手**：将仓库放入项目，告诉它“请读 agent-prd/SKILL.md，按里面的流程整理我的点子”，然后描述需求。
- **支持上传附件的聊天工具**：上传 `SKILL.md` 和 `references/` 中的全部 Markdown 文件，再描述想法。工具可以生成文件时直接下载，也可以从对话中复制两份文档。

## 技术方案里的组件是怎么选的？

技能从需求中提取 14 项特征，例如“要不要定时运行”“会不会写入外部系统”，记录每项判断的依据，再按固定规则对 17 个组件逐项给出“必选、二期、待确认、放弃”。你可以沿着选型表追溯每项决定，也可以在需求变化后用相同规则重新计算。

选型脚本使用 Python 3.8+ 标准库，在本地运行，无需额外的 API Key。无法运行 Python 的聊天工具可以按同一套规则手工推导。交付前，技能会核对用户原话、权限边界、失败处理和验收条件，并在方案中记录自查结果。

[查看组件与选型规则](references/components.md) · [查看选型脚本](scripts/select_components.py)

## 拿到初稿后

- **补细节**：“账本就存在本机，我来回答其他待确认问题。” 技能会补全当前版本，并更新受影响的方案。
- **改需求**：“再加一个每周日发来本周汇总的功能。” 技能会保留旧版，重新判断定时调度等组件，在新版方案中说明变化。
- **交给开发**：确认范围后，把两份文件交给 AI 编程工具，告诉它“按 PRD.md 和 方案.md 开始开发”。
